# Blend-mode reference renders

Paint.NET 5.2 exports that pin Hoshi's blend modes and FP32→8-bit rounding to
the real thing ([ADR 0004](adr/0004-pixel-precision-blend-modes.md), slice 6).
Until they exist, blend tests compare within a tolerance.

## Inputs

`crates/hoshi-core/tests/fixtures/blend/bottom.png` and `top.png`, both
512×512 straight RGBA8 PNG with no colour profile. They are generated by
`python3 scripts/blend_fixtures.py` (standard library only, byte-identical on
every machine). Each image has four 256×256 quadrants:

| Quadrant | Bottom layer | Top layer | Checks |
| --- | --- | --- | --- |
| Top-left | opaque gray ramp, value = x | opaque gray ramp, value = y | every 8-bit base × blend pair (65,536) for separable modes and rounding |
| Top-right | orange, alpha 0…255 by row band | blue, alpha 0…255 by column band | partial alpha on both layers, including 0, 1, 127/128, 254, 255 |
| Bottom-left | hue sweep (x) × saturation (y) | 16 hues × 4 saturations × 4 values | saturated colour pairs and channel cross-talk; ready for non-separable modes Paint.NET 6.0 may add |
| Bottom-right | edge colours (black, white, 1, 254, 127/128, primaries); RGB hidden under alpha 0; seeded noise | edge colours, noise | extremes, premultiplication, hidden-RGB handling, broad random coverage |

## Owner steps (Windows, Paint.NET 5.2)

1. Open `bottom.png` in Paint.NET 5.2.
2. **Layers → Import from File** → `top.png`. It becomes the top layer.
3. With the top layer selected, for each blend mode:
   1. **F4** (Layer Properties) → Blend mode → choose it → OK.
   2. **File → Save As** → PNG named `pdn-<mode>.png`, e.g. `pdn-multiply.png`.
      Choose **Flatten** when asked, then press **Ctrl+Z** to undo the flatten.
4. Modes (14): Normal, Multiply, Additive, Color Burn, Color Dodge, Reflect,
   Glow, Overlay, Difference, Negation, Lighten, Darken, Screen, Xor.
5. Also export Normal, Multiply, Screen and Overlay with the top layer's
   **Opacity at 128** in Layer Properties: `pdn-<mode>-o128.png`.
6. Upload all files (about 18) to
   `crates/hoshi-core/tests/fixtures/blend/paintnet/` with GitHub's web
   **Add file → Upload files**, and mention the Paint.NET version in the commit
   message.

Keep the defaults otherwise: 8-bit PNG, no metadata changes. The canvas has no
background layer, so transparent areas stay transparent in the exports.
